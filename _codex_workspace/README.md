# hospitaFXjyy 协作工作区

这里存放项目协作约定、任务分工、接口契约和阶段性验收记录。

约定：

- 这里的文件是辅助资料，不替代源码和数据库迁移文件。
- 新功能优先新增独立目录或组件，避免多人同时修改 `src/App.jsx`、`src/panels.jsx` 和 `src/styles.css`。
- 任何进入 `main` 的代码都必须经过构建或测试验证。
